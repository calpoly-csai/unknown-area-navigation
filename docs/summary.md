### Summary

Despite the name, deep learning models don’t learn.

Once trained on a set of data, models can only act within that domain and can’t apply it’s knowledge all scenarios that might occur in the real word.  In the context of autonomous navigation, models trained on high infrastructure urban areas like San Francisco might not understand how to handle an rural vehicle like a tractor, or an pedestrian in an costume.  As environments become less and less predictable, the current state of autonomous navigation becomes less useful

Our goal is to develop a pipeline that can supplement autonomous navigation in unfamiliar settings. We will explore this with technologies like meta learning, few-shot learning, unknown object detection, and contextual scene understanding.
